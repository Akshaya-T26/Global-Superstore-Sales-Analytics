
# Global Superstore – Sales Performance Analysis

## Internship
Skill Nexis – Data Science Internship
Week 1: Excel & Data Fundamentals

## Project Overview
This project analyzes the Global Superstore dataset using Microsoft Excel. The objective is to clean the data, perform statistical analysis, summarize sales performance, and create a sales dashboard.

## Dataset
Global Superstore 2016

Worksheets:
- Orders
- Returns
- People

## Tasks Completed

1. Removed duplicate records and inspected missing values.
2. Created a region-wise sales Pivot Table.
3. Calculated Mean, Median, and Mode using Excel formulas.
4. Applied Conditional Formatting to highlight the Top 10 sales.
5. Created a category-wise revenue Bar Chart.

## Main Dashboard

The dashboard includes:
- Total Revenue
- Total Profit
- Sales by Product Category
- Yearly Sales Trends (2012–2015)
- Revenue by Product Sub-Category

## Tools Used
- Microsoft Excel 2021/2024
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Excel Formulas
- Data Visualization

## Data Cleaning
- Checked for duplicate records.
- Inspected missing values.
- Retained missing Postal Codes instead of replacing them with incorrect values.

## Dataset Limitation
The provided dataset does not contain a Department column. Product Sub-Category was used as a detailed revenue breakdown instead.
